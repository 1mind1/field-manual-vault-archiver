Field Manual Vault Archiver — V5.0.2 release candidate (RC3)

Windows: Double-click START_WINDOWS.bat. Choose your existing Field Manual
Vault root. Option 3 selectively downloads PDFs/EPUBs. Option 7 refreshes
selected catalog categories without downloading any manuals. Options 1 and 6
are completely offline. Choose a polite discovery pacing profile as prompted.

Requirements: Python 3.10+ (standard library; no pip packages).
Read README.md for setup, storage caps, safety, tests and GitHub release notes.

For offline metadata repair, select option 6 and review the coverage report
and Field_Manual_Metadata_Repairs.csv in your existing Vault root.
