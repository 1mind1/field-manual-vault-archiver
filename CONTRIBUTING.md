# Contributing

Thanks for considering a contribution. This is an independent utility, not connected to T.REX ARMS.

- Please keep code runnable on Python 3.10+ without required third-party dependencies, and preserve the Windows launcher.
- Add deterministic offline tests for parsers, caching, download caps, and filesystem behavior.
- Keep requests polite: no authentication bypass, anti-bot circumvention, aggressive concurrency, or silent downloads.
- Avoid storing any real downloaded PDFs/EPUBs, generated catalogs, cache databases, tokens, or user file paths in commits.
- Maintain backwards compatibility with the organized v3 layout where possible.
- When reporting bugs, provide a minimal redacted URL/HTML example and Python version; do not upload an entire manual.
- All contributions are assumed to be offered under the repository's Apache License 2.0.
